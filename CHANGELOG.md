# Changelog

All notable changes to Tumble are documented here. The format follows
[Keep a Changelog](https://keepachangelog.com) loosely and the project uses
semantic versioning.

## [0.4.0]
### Added
- Dynamic AABB tree and sweep-and-prune broadphases.
- Extended constraints: weld, prismatic, motor, mouse and pulley.
- Island detection with union-find and per-island sleeping.
- Procedural scene generators, force fields, wind, buoyancy and conveyors.
- SVG and JSON exporters; ASCII renderer.
- Time-of-impact (conservative advancement) and circle shape casting.
- Fixed-timestep driver, frame recorder and render interpolation.

## [0.3.0]
### Added
- Sequential-impulse solver with distance and revolute joints.
- Text and binary scene formats with defensive loaders.
- GJK distance, raycasting and spatial-hash grid.

## [0.2.0]
### Added
- Polygon and circle shapes, mass properties, SAT narrowphase.

## [0.1.0]
### Added
- Vectors, transforms, AABBs and the world container.
